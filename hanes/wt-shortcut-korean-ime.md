# 터미널 단축키가 한글 상태에서 안 먹음 + Shift+문자가 타이핑을 가로챔

- 기록: 2026-08-25
- 분야: Windows Terminal, 한글 IME

## 문제

- Windows Terminal에서 분할 단축키가 한글 입력 상태에서는 안 되고 영어 상태에서만 됨.
- 영어 상태에서 대문자 D를 타이핑하려고 Shift+D를 누르면 pane이 분할돼버림 (대문자 D 입력 불가).

## 원인

1. `shift+d` 같은 **타이핑용 조합을 단축키로 등록**해서 대문자 입력을 가로챈 것 (설정 실수).
2. 한글 IME가 켜져 있으면 문자키가 **글자 조합용으로 IME에 먼저 소비**되어 터미널 단축키까지 도달하지 않음. 이건 WT+IME의 구조적 특성이라 어떤 키를 써도 문자키 조합은 한글 모드에서 불안정.

## 해결

- `shift+d` 바인딩 삭제 → 대문자 타이핑 복구.
- 분할 단축키를 Ctrl/Alt 포함 조합으로 재배치: 오른쪽 분할 `Alt+Shift+D`, 아래 분할 `Ctrl+Shift+D`.
- 단축키 누르기 전에 한/영 키로 영어 모드 전환하는 습관. 확실히 하려면 F키·방향키 조합 사용.
- 세션 매니저에 재발 방지 장치 추가: Shift+문자/Ctrl+C 등 위험 조합 등록 시 주의 모달, 키 충돌 시 빨간색 경고.

## 참고

- 세션 매니저 단축키 편집: http://localhost:7777 → 터미널 단축키
