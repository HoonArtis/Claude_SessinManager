# 블렌더 MCP 두 개 설치 시 이름·포트 충돌

- 기록: 2026-08 (이전 발생 건 정리)
- 분야: Blender, MCP

## 문제

블렌더 MCP를 두 종류(ahujasid판, 공식판) 깔았더니 도구 이름이 겹치고 포트가 충돌해 연결이 불안정.

## 원인

두 애드온이 같은 역할의 서버를 각자 띄우려 하고, MCP 서버 이름도 비슷해서 클라이언트가 혼동.

## 해결

- **ahujasid판만 활성화 (포트 9876), 공식판은 비활성.**
- 블렌더 애드온 설정에서 둘 다 켜져 있지 않은지 확인하는 게 첫 점검 포인트.
- MCP 연결이 이상하면: ① 블렌더 쪽 애드온 상태 → ② 9876 포트 리슨 여부 → ③ Claude 쪽 MCP 설정 순으로 확인.
