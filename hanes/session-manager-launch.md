# 세션 매니저 실행 시 cmd 창이 뜨고, 업데이트 체크로 초기 로딩이 느림

- 기록: 2026-08-25
- 분야: Claude 세션 매니저 (이 저장소)

## 문제

1. 바탕화면 바로가기로 실행하면 최소화된 cmd 창이 하나 남음.
2. 실행 시 git pull을 먼저 하도록 넣었더니 네트워크만큼 시작이 느려짐.

## 원인

1. `launch.vbs → launch.bat → start cmd` 구조라 서버가 cmd 창 안에서 돌았음.
2. pull을 직렬로 기다린 뒤 서버를 켜는 구조였음.

## 해결

1. launch.vbs가 **node를 직접 창 없이 실행** (bat 경유 제거). launch.bat은 로그 보는 수동 실행용으로만 유지.
2. **즉시 시작 + 백그라운드 확인** 구조로 변경: 서버는 바로 켜고, 서버가 뒤에서 `git fetch`만 수행 → 새 버전이 있으면 페이지에서 [지금 업데이트 / 나중에 / 1주일 안 보기] 모달로 사용자가 결정. 지금 업데이트를 누르면 pull 후 서버 자동 재시작 + 새로고침. 오프라인/오류면 기존 서버 그대로 유지.
3. 브라우저 탭을 모두 닫으면 서버가 15초 뒤 자동 종료되므로, 다음 실행에서 자연스럽게 새 코드가 적용됨.

## 참고

- "1주일 안 보기"는 브라우저 localStorage(`csm-update-snooze-until`)에 저장.
