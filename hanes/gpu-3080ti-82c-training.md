# 3DGS 학습 중 GPU 82°C까지 상승

- 기록: 2026-08-25
- 분야: GPU (RTX 3080 Ti), 학습 발열

## 문제

가우시안 스플래팅 학습 중 GPU 코어가 82°C까지 올라감. 위험한지 판단 필요.

## 원인/판단 기준

- 코어 82°C는 스로틀 시작(83°C) 직전 — 당장 위험은 아니나 카드가 낼 수 있는 최대 발열 상태.
- 3080 Ti의 진짜 위험은 **GDDR6X VRAM 정션 온도** — 코어보다 20~30도 높게 가며 110°C에서 스로틀. 코어 82면 VRAM은 95~105°C 추정.
- `nvidia-smi`에는 VRAM 온도가 안 나옴 → **HWiNFO64**의 "GPU Memory Junction Temperature"로 확인해야 함.
- 기준: 코어 80 이하 + VRAM 100 이하면 장시간 학습 OK. 83부터 클럭 저하, 93에서 보호 종료.

## 해결

1. **전력 제한** (효과 최대): `nvidia-smi -pl 280` (350W→280W, 관리자 권한, 재부팅 시 원복) — 온도 6~10도 하락, 속도 3~5% 손해
2. 팬 커브 공격적으로 (Afterburner, 70°C에 80%)
3. 케이스 측면 열어 테스트 — 5도 이상 떨어지면 케이스 환기가 병목

## 참고

- 장기 고온 유지의 실제 리스크는 급사보다 VRAM·전원부 수명 단축
