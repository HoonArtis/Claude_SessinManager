# I225 랜카드 링크 플래핑 / 로컬망 구성

- 기록: 2026-08 (이전 발생 건 정리)
- 분야: 네트워크

## 문제

Intel I225 랜카드 쪽 링크가 불안정(플래핑)했고, 장비 간 로컬 연결용 설정이 필요했음.

## 해결/구성

- 해당 포트는 **로컬망 전용, 고정 IP 10.10.10.14** (DHCP 금지 — 다른 장비와의 직결망이라 DHCP 서버가 없음).
- 플래핑이 재발하면 **다음 순서는 케이블 교체** (드라이버·설정보다 케이블이 유력 용의자).

## 참고

- 인터넷용 회선과 혼동 금지 — 이 포트에 게이트웨이/DNS 넣지 말 것.
