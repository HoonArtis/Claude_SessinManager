# 맥에서 온 한글 폴더를 도구가 못 찾음 (NFD 정규화)

- 기록: 2026-08 (이전 발생 건 정리)
- 분야: 파일시스템, 한글 경로

## 문제

맥에서 복사해온 한글 이름 폴더/파일을 윈도우에서 Claude Code의 Write/Bash 도구가 "경로 없음"으로 못 찾음. 탐색기에서는 멀쩡히 보임.

## 원인

macOS는 한글 파일명을 **NFD**(자모 분해형)로 저장. 윈도우/도구는 **NFC**(완성형)로 경로를 다루므로, 눈으로는 같아 보여도 바이트가 달라 매칭 실패.

## 해결

- PowerShell **와일드카드로 우회**: `Get-ChildItem "C:\...\후백제*"` 처럼 패턴 매칭으로 접근하면 실제 경로 객체를 얻을 수 있음.
- 근본 해결은 폴더명을 영문으로 바꾸거나, 복사 시 이름을 다시 타이핑(NFC로 저장됨).
- 새 프로젝트 폴더는 처음부터 영문 케밥케이스로 만드는 게 안전.
